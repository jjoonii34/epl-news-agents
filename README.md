# epl-news-agent

EPL 이적·부상 소식을 기자 신뢰도 순으로 모아서 한국어로 요약해주는 웹앱.
요약이 얼마나 정확한지 자동으로 채점하고, 프롬프트 버전별로 비교한다.

| 상태 | 기획 중 (2026-11) |
| 배포 | 아직 |

## 요구사항 

리버풀 소식을 제대로 보려면 로마노, 온스테인, 폴 조이스, 제임스 피어스를 따로 찾아봐야 한다.
뉴스 검색으로는 타블로이드 추측 기사가 섞여 들어오고, 같은 소식이 매체마다 반복된다.

그리고 LLM 요약을 믿고 쓰려면 얼마나 틀리는지 알아야 하는데, 그걸 재는 도구가 서비스에 붙어 있는 경우가 별로 없다.
이 프로젝트는 그 측정 파이프라인까지 같이 만들 예정이다.

## 기능

- 공개 RSS에서 2시간마다 기사 수집, 중복 제거
- 같은 사건 기사를 묶어서(issue) 한국어 요약, 출처 기자 표시
- 기자 티어(1~3)로 피드 정렬
- 요약마다 정확/틀림 반응 버튼 → 채점 데이터로 사용
- 관리자 화면: 프롬프트 버전별 할루시네이션률, 누락률, LLM 판정자와 사람 채점 일치율
- 5대 리그 경기 결과 (당일/전일)

## 품질 측정

요약 하나마다 LLM 판정자가 문장 단위로 원문 대조 → 근거 없는 문장 비율(할루시네이션률), 필수 사실 누락률을 계산.
일부는 직접 채점해서 판정자와 얼마나 맞는지(Cohen's κ) 같이 기록.
프롬프트나 모델을 바꾸면 같은 테스트셋으로 N회 반복해서 평균·분산 비교.

수치는 배포 후 여기에 적음.
